Frequently asked questions

Questions about browser-rendered crawling

What does browser-rendered crawling mean?

It means the crawler can load a page in a browser engine before extracting SEO data, rather than relying only on the initial response HTML.

Can CrawlLoom find JavaScript-generated content?

Yes. When browser rendering is available, CrawlLoom extracts rendered text, links, headings, metadata, and page resources after the page has had an opportunity to hydrate.

Is the dashboard publicly accessible?

No. CrawlLoom is a private workspace. A sign-in is required to run crawls, view audit history, inspect results, or export reports.
